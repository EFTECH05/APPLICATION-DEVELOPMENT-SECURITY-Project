# Banking Payment System (Task 2 Project)

## 📌 Overview
This project is a secure banking simulation system built using ASP.NET Core MVC. It supports user payments, admin approval workflow, and SWIFT processing.

## 👥 User Roles
- User: Makes payments and views transactions
- Admin: Approves/rejects payments and handles SWIFT flow
- SuperAdmin: Manages system-level access

## 🔐 Features
- Login & Registration
- OTP verification during login
- Payment processing system
- Admin approval workflow
- SWIFT transaction simulation
- PDF bank statement generation

## ⚙️ Technologies Used
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- iTextSharp (PDF generation)

## 💳 Payment Flow
User → OTP Login → Payment → Admin Verification → SWIFT Processing → Completed

## 🚀 How to Run
1. Clone repository
2. Open in Visual Studio
3. Restore NuGet packages
4. Update connection string
5. Run database migrations (if needed)
6. Start project
